# 像素英语小镇：MVP 需求文档

## 1. 产品目标

将现有英语阅读应用升级为“像素英语小镇”。像素小镇是产品的视觉入口和导航空间；MVP 只开放学习广场，其余建筑以“建设中”呈现。用户可阅读文章、完成学习、获得徽章、在广场看到实时学习动态与排行榜，并使用自己提供的 DeepSeek API Key 生成练习题。

## 2. 范围

### 本期包含

- 像素小镇落地页、登录/注册动效和小镇总览。
- 邮箱密码注册/登录；注册时填写昵称，已登录的回访用户直接显示“欢迎回到小镇”。
- 学习广场：实时在线人数、实时学习动态、去学习入口、排行榜。
- 学习页：文章列表、文章学习区（双语阅读、音频、逐词高亮、完成动作）、DeepSeek AI 刷题区。
- 个人中心：学习统计、已获/未获徽章、DeepSeek Key 会话配置。
- 管理后台：在既有文章和用户管理基础上，增加 JSON 徽章类型配置、校验、启停和发布。

### 本期不包含

- 手机号注册/登录和短信验证码；界面可显示“即将开放”，但不提供不可用的表单入口。
- 私聊、自由聊天、好友关系、头像装扮、地图建设、付费与积分商城。
- 其他可进入建筑或功能页面。

## 3. 用户与权限

| 角色     | 权限                                                               |
| -------- | ------------------------------------------------------------------ |
| 游客     | 浏览落地页和登录/注册入口；不可进入小镇功能页。                    |
| 普通用户 | 进入学习广场、学习文章、使用自己的临时 AI Key 刷题、查看个人中心。 |
| 管理员   | 继承普通用户能力，并管理文章、用户、徽章 JSON 配置。               |

昵称在注册时必填，长度 2–16 个字符，去首尾空格后全站唯一；用户在广场动态和榜单中使用昵称展示。邮箱全局唯一。密码规则沿用现有系统配置。

## 4. 核心流程

### 4.1 进入与认证

1. 游客访问 `/`，看到全屏像素小镇落地页。
2. 点击“进入小镇”或画面主交互后，小镇背景向上滑动，露出像素风认证卡片。
3. 新用户选择注册，填写昵称、邮箱和密码；注册成功后自动登录并进入 `/town`。
4. 老用户填写邮箱、密码登录并进入 `/town`。
5. 已有有效登录状态的用户再次访问 `/`，不显示认证表单，直接显示“欢迎回到小镇”，点击后进入 `/town`。登录状态使用安全的 HttpOnly Cookie 持久化，默认有效期为 30 天；用户主动退出、会话过期或服务端撤销后需要重新登录。

### 4.2 小镇与学习广场

1. `/town` 显示小镇全貌；“学习广场”可进入。
2. 其他建筑为灰显/锁定状态，点击仅显示“建设中，敬请期待”，不跳转。
3. 进入 `/plaza` 后，客户端建立实时连接并加入广场在线状态。
4. 页面右上角实时展示去重后的在线用户数。同一用户打开多个标签页仅计为一名在线用户。用户进入广场时，进入者本人获得“欢迎来到学习广场”的本地 Toast；服务端同时向广场广播“{用户名} 进入了学习广场”。为避免刷新刷屏，同一用户 5 分钟内最多广播一次进入动态。
5. 用户点击“公告栏”后查看最近 50 条广场动态；点击“学习榜”后打开排行榜，并可切换今日排行榜和连续学习榜。榜单与动态历史均不常驻遮挡广场画面。
6. 用户完成一篇文章后，服务端写入完成记录、计算徽章，并向广场广播完成文章及新获得徽章的系统动态；进入、完成文章和获得徽章的实时动态使用相同 Toast 展示，所有在线用户在 3 秒内看到动态与相应排行榜更新。

### 4.3 小镇建筑规划

学习广场位于小镇中央，以喷泉、公告栏、长椅和旗帜构成，是唯一开放的功能区域。围绕广场的建筑用于表达英语能力地图，并为后续功能预留入口：阅读小屋（文章阅读）、词汇宝库（背词）、语法塔楼（语法）、拼写蜂巢（拼写）、单词竞技场（闯关）、对话咖啡馆（AI 口语）、写作工坊（写作批改）、听力小屋（听力）、发音邮局（跟读）、每日任务屋（日常目标）、知识花园（成就展示）、小镇大厅（公告/活动）和码头（课程地图）。

本期除学习广场外均为不可用热点：低饱和遮罩、锁定图标和“建设中”提示；不产生空页面、假功能或路由跳转。

### 4.4 学习与 AI 刷题

桌面端 `/learn` 为三栏布局：左侧文章列表，中间文章学习区，右侧 AI 刷题区。中间区包含双语文章、音频播放、逐词高亮和“完成学习”按钮。移动端以阅读区为主体，文章列表和 AI 刷题分别使用抽屉/底部面板打开。

AI 区首次使用要求输入 DeepSeek API Key；Key 仅保存在当前浏览器会话内存或 `sessionStorage`，退出浏览器会话后失效。生成题目时 Key 通过受保护的服务端代理临时转发，服务端不得记录、持久化或在错误日志中输出 Key。

### 4.5 个人中心与徽章

`/me` 展示累计学习天数、完成文章数、连续学习天数、学习历史和徽章墙。徽章是成就体系，不是可消费积分：满足发布中的徽章规则时自动授予一次；徽章不参与兑换，也不产生 XP。

## 5. 排行榜与实时动态

本期排行榜使用两个明确、可从学习记录计算的指标：

| 榜单       | 统计周期              | 排序规则                                                                           |
| ---------- | --------------------- | ---------------------------------------------------------------------------------- |
| 今日学习榜 | 当日（Asia/Shanghai） | 完成文章数降序，相同数量按最早完成时间排序。                                       |
| 连续学习榜 | 当前连续学习周期      | 连续学习天数降序；相同天数按该连续周期内累计完成文章数降序，再按最近学习时间排序。 |

广场动态仅由系统产生，类型包括 `ENTER_PLAZA`、`ARTICLE_COMPLETED` 和 `BADGE_EARNED`。每条动态展示昵称、行为、必要的文章/徽章名称和发生时间；不暴露邮箱、API Key 或文章正文。动态保留最近 50 条，不提供用户自由输入或聊天入口。

## 6. 验收标准

- 游客可看到像素小镇落地页；认证动效完成后可注册或登录。
- 已登录用户访问入口页时可直接进入小镇，并看到“欢迎回到小镇”。
- 仅学习广场可进入；其他建筑只显示“建设中”提示。
- 两个不同浏览器进入广场后，在线人数在 3 秒内一致；同一用户多个标签页仅计为一人。
- 用户进入广场后，所有在线用户在 3 秒内看到在线人数更新；同一用户 5 分钟内反复进入不重复产生进入动态。
- 任一用户首次完成某篇文章后，进度只增加一次；所有在线用户在 3 秒内看到完成动态和榜单刷新。
- 文章完成后符合规则的徽章仅授予一次，并在个人中心和广场动态中正确显示。
- 未配置 Key 时不可生成 AI 题；配置有效 DeepSeek Key 后可以生成题目；刷新/新会话后需要重新输入 Key。
- 管理员不能发布不符合 JSON Schema 的徽章配置；已获得的历史徽章在配置变更或停用后仍可显示。

## 7. 非功能要求

- 所有“当天”、连续学习、日榜计算统一使用 `Asia/Shanghai`。
- 支持断线重连；重连后重新获取广场快照，确保在线人数、动态和榜单最终一致。
- 尊重系统“减少动态效果”设置；认证场景在此模式下直接切换，不执行上滑动画。
- 不把 API Key 写入数据库、前端埋点、请求日志或错误日志。
